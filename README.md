# Master_UTCN_AC_Genetic_Algorithms_for_Optimizing_the_Scheduling_of_Electrical_Devices_Python
Tema lucrării constă în dezvoltarea și evaluarea unei metode de optimizare 
pentru planificarea funcționării dispozitivelor electrice dintr-o locuință, cu 
respectarea simultană a trei obiective: reducerea costului energiei electrice, 
menținerea confortului utilizatorului și uniformizarea consumului pe parcursul 
zilei.
